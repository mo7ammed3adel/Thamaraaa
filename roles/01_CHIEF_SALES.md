# 👔 Chief Sales — داشبورد شيف المبيعات

---

## 🎯 الدور الوظيفي
الـ Chief Sales هو أعلى سلطة في منظومة المبيعات، مسؤول عن الإشراف الكامل على قسمي **TeleSales** و**Sales** معاً، ومتابعة الأداء العام وتحليل الأرقام واتخاذ القرارات الاستراتيجية.

---

## 🗂️ أقسام الداشبورد

---

### 1. 📊 Overview Dashboard (الصفحة الرئيسية)

#### KPI Cards — أرقام حية في أعلى الصفحة:
| البطاقة | الوصف |
|---------|--------|
| إجمالي الـ Leads الداخلة | عدد الـ Leads اللي دخلت النظام (اليوم / الأسبوع / الشهر) |
| إجمالي الاجتماعات المحجوزة | عدد الاجتماعات اللي حجزها TeleSales |
| إجمالي الاجتماعات اللي حصلت | عدد الاجتماعات اللي اتعملت فعلاً مع Sales |
| إجمالي الصفقات المغلقة | عدد الـ Deals اللي اتقفلت |
| إجمالي الإيرادات | القيمة المالية الكلية للصفقات المغلقة |
| معدل التحويل TeleSales→Meeting | نسبة Leads اللي اتحولوا لاجتماعات |
| معدل الإغلاق Sales | نسبة الاجتماعات اللي اتحولت لصفقات |

> كل رقم قابل للضغط عليه → يظهر قائمة بالعملاء اللي بيشكلوا الرقم ده (Drill-Down)

#### فلاتر زمنية:
- اليوم / هذا الأسبوع / هذا الشهر / ربع السنة / Custom Range

---

### 2. 📞 TeleSales Performance

#### ملخص أداء القسم:
- إجمالي الـ Leads الموزعة
- إجمالي المكالمات اللي اتعملت
- نسبة الاجتماعات المحجوزة
- نسبة الخطأ / الانشغال / عدم الرد
- نسبة العملاء الباردين اللي اتحولوا لـ Leads

#### جدول أداء موظفي TeleSales:
| العمود | الوصف |
|--------|--------|
| اسم الموظف | - |
| عدد الـ Leads عنده | - |
| مكالمات تمت | - |
| اجتماعات محجوزة | - |
| Target الشهري | - |
| نسبة الإنجاز | شريط تقدم % |
| آخر نشاط | - |

> الضغط على اسم الموظف → تفاصيل كاملة لأدائه + سجل مكالماته

### 4. 🔄 Pipeline View (خط سير العملاء)

عرض بصري (Kanban أو Timeline) يوضح:
- كم عميل في مرحلة TeleSales
- كم عميل في مرحلة انتظار الاجتماع
- كم عميل في مرحلة التفاوض مع Sales
- كم عميل اتحول لـ Account Management
- كم عميل خسران / في الـ Recycle Bin

---

### 5. 💰 Revenue & Deals

|--------|--------|

---

### 6. ⚠️ Warnings & Alerts

- قائمة بكل الـ Warnings اللي اتبعتت على عملاء
- اسم من بعت الـ Warning + تاريخه
- حالة القراءة (مين قرأ ومين لسه)
- إمكانية إضافة Warning جديد على أي عميل

---

### 7. 🗑️ Recycle Bin Overview

- عرض كل العملاء المفقودين (Lost Leads)
- تصنيف: خسران من TeleSales / خسران من Sales Meeting
- إمكانية إعادة توزيع على TeleSales أو أرشفة
