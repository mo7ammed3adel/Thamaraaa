# 👨‍💻 Social Media Agent

## الدور الوظيفي
ينفذ خطة السوشيال ميديا للعملاء المخصصين له، يشوف رحلة العميل الكاملة، ويرفع تاسكات للتصميم والموشن عند الحاجة.

---

## 🗂️ أقسام الداشبورد

### 1. 📊 Overview Dashboard

#### KPI Cards:
| البطاقة | الوصف |
|---------|--------|
| إجمالي عملائي النشطين | - |
| تاسكاتي الجارية | - |
| تاسكات انتظار ردود | - |
| Warnings نشطة | - |

---

### 2. 📋 My Clients

جدول عملائه:
| العمود | الوصف |
|--------|--------|
| اسم العميل | - |
| نوع الباقة | - |
| حالة المشروع | - |
| تاسكات رافعها للعميل ده | - |
| Warnings | - |

> الضغط على عميل → صفحة تفاصيله الكاملة

---

### 3. 👁️ Client Detail Page

عند الضغط على عميل:

#### أ) معلومات العميل:
- الاسم، المجال، رابط المتجر، نوع البيزنس

#### ب) Client Journey Timeline:
- رحلة العميل الكاملة من TeleSales → Sales → Account Management → التيم
- كل الملاحظات اللي كتبها أي موظف في أي مرحلة
- تفاصيل الصفقة والعقد

#### ج) Notes الكاملة:
- ملاحظات TeleSales Agent
- ملاحظات Sales Agent
- ملاحظات Account Manager
- ملاحظات أي موظف تاني شغل على العميل
- مرتبة زمنياً + اسم الكاتب

#### د) My Tasks لهذا العميل:
- التاسكات اللي أنا رافعها للعميل ده
- حالة كل تاسك

---

### 4. ✅ Task Assignment (رفع تاسك)

#### نافذة رفع تاسك جديد:
- العميل المرتبط بالتاسك
- **نوع التاسك:**
  - `Graphic Design` → يروح لـ Leader Graphic Design
  - `Motion Graphic` → يروح لـ Leader Motion Graphic
  - `UI/UX Design` → يروح لـ Leader UI/UX
- وصف التاسك بالتفصيل
- رابط مرجعي (صور، مستندات، إلخ)
- Deadline المطلوب

> بعد الرفع، التاسك بيروح للـ Leader المسؤول اللي يوزعه على الـ Agent

#### جدول تاسكاتي:
| العمود | الوصف |
|--------|--------|
| اسم التاسك | - |
| العميل | - |
| ذاهب لـ | Graphic / Motion / UI |
| الحالة | Pending / In Progress / Done |
| تاريخ الرفع | - |
| تاريخ البداية | - |
| تاريخ الانتهاء | - |
| رابط التاسك | - |

---

### 5. ⚠️ Warnings
- Pop-up إجباري على أي Warning على عملائه
- لازم يضغط "تم القراءة"
