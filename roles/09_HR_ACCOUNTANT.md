# 💰 Accountant (المحاسب)

## الدور الوظيفي
مسؤول عن متابعة الشؤون المالية للشركة، من الصفقات المغلقة والعقود والدفعات وجداول الأقساط ومتابعة التحصيل.

---

## 🗂️ أقسام الداشبورد

### 1. 📊 Overview Dashboard

#### KPI Cards:
| البطاقة | الوصف |
|---------|--------|
| إجمالي الإيرادات المحصلة | إجمالي المدفوع فعلاً |
| إجمالي قيمة العقود | إجمالي قيمة كل الصفقات المغلقة |
| المتبقي للتحصيل | الفرق بين الكل والمحصل |
| دفعات مستحقة هذا الشهر | - |
| دفعات متأخرة | - |
| صفقات جديدة هذا الشهر | - |

---

### 2. 💼 All Deals (كل الصفقات)

#### جدول كل الصفقات المغلقة:
| العمود | الوصف |
|--------|--------|
| اسم العميل | - |
| نوع الباقة | SEO / Social / Full |
| قيمة العقد الكلية | - |
| الدفعة الأولى | - |
| المبلغ المحصل حتى الآن | - |
| المتبقي | - |
| طريقة الدفع | نقد / تحويل / أقساط / تابي / تمارا |
| تاريخ الصفقة | - |
| Sales Agent | - |
| حالة الدفع | مكتمل / جزئي / متأخر |

> الضغط على عميل → تفاصيل كاملة بجدول الدفعات

---

### 3. 📅 Installments Schedule (جدول الأقساط)

#### جدول كل الدفعات القادمة:
| العمود | الوصف |
|--------|--------|
| اسم العميل | - |
| قيمة الدفعة | - |
| تاريخ الاستحقاق | - |
| الحالة | مدفوع / مستحق / متأخر |
| ملاحظات | - |

> فلتر: هذا الأسبوع / هذا الشهر / متأخرة فقط

---

### 4. ⚠️ Overdue Payments (الدفعات المتأخرة)

- قائمة بكل الدفعات اللي تجاوزت تاريخ الاستحقاق
- اسم العميل + قيمة الدفعة + عدد أيام التأخير
- زرار للتواصل مع Account Manager المسؤول للمتابعة

---

### 5. 📊 Financial Reports

- تقرير إيرادات شهري / ربع سنوي / سنوي
- تقرير أداء المبيعات (أعلى Sales Agents إيراداً)
- تقرير توزيع الباقات (SEO vs Social vs Full)
- تقرير طرق الدفع الأكثر استخداماً

---

### 6. 📤 Export

- تصدير أي تقرير مالي بصيغة Excel / PDF
