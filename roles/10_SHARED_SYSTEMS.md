# ⚠️ 1. Warning / Alert System

## الوصف
نظام تحذيرات إجبارية يضمن وصول أي شكوى أو مشكلة للعميل لكل موظف شغال عليه فوراً وبدون استثناء.

---

## من يقدر يرسل Warning؟
- `account_manager` ✅
- `sales_agent` ✅

---

## آلية الإرسال

### الخطوات:
1. الـ Account Manager أو Sales Agent بيضغط زرار **⚠️ Warning** في صفحة العميل
2. تظهر نافذة (Modal) لكتابة تفاصيل التحذير:
   - **موضوع التحذير** (حقل نص قصير)
   - **تفاصيل الشكوى / المشكلة** (حقل نص طويل)
   - **درجة الأهمية:** Low / Medium / High / Critical
3. يضغط **إرسال**
4. النظام يحدد تلقائياً كل الموظفين المرتبطين بالعميل ده

---

النظام يحدد تلقائياً كل الموظفين اللي العميل موجود في داشبورداتهم:

---

## آلية الاستقبال (Pop-up إجباري)

### عند دخول الموظف الداشبورد أو كان شغال:
1. **Pop-up إجباري** يظهر على شاشته بالكامل
2. يعرض:
   - اسم العميل
   - موضوع التحذير
   - تفاصيل الشكوى
   - درجة الأهمية
   - اسم من أرسل الـ Warning + الوقت
3. **مفيش زرار X** لإغلاقه
4. الزرار الوحيد الموجود: **"✅ تم القراءة والاستيعاب"**
5. بعد الضغط:
   - يتسجل في قاعدة البيانات: اسم الموظف + توقيت القراءة
   - البوب-آب يختفي
   - الموظف يقدر يكمل شغله

---

## متابعة الـ Warning

### في داشبورد من أرسل الـ Warning:
- قائمة بكل الموظفين اللي المفروض يستقبلوا الـ Warning
- حالة كل موظف: ✅ قرأ (+ الوقت) / ⏳ لسه ما قرأش

### في داشبورد Chief Sales وHead Account Manager:
- قائمة كاملة بكل الـ Warnings النشطة
- حالة القراءة لكل موظف

---

## حالات الـ Warning:
- **Active** — لسه ما اتحلتش
- **Resolved** — تم حلها (يغيرها من بعت الـ Warning أو Head Account Manager)
- **Archived** — تم أرشفتها

# ✅ 3. Task Assignment System

## الوصف
نظام موحد لرفع التاسكات من الفرق التنفيذية لفرق التصميم والمحتوى.

---

## من يقدر يرفع تاسك؟
| الدور | يقدر يرفع لـ |
|-------|-------------|
| `agent_social_media` | Graphic / Motion / UI |
| `agent_media_buyer` | Graphic / Motion / UI |
| `agent_seo` | Content SEO + Graphic / Motion / UI |
| `account_manager` | Content SEO + Graphic / Motion / UI |

---

## مسار التاسك:
```
Agent يرفع تاسك
        ↓
التاسك يوصل لـ Leader المسؤول (Pending)
        ↓
Leader يوزع على Agent المناسب
        ↓
Agent يضغط Start → In Progress
        ↓
Agent يضغط Done → Completed
        ↓
إشعار لـ Account Manager + من رفع التاسك
```

---

## بيانات التاسك:
| الحقل | الوصف | إلزامي؟ |
|-------|--------|---------|
| العميل المرتبط | dropdown | ✅ |
| نوع التاسك | Graphic / Motion / UI / Content | ✅ |
| عنوان التاسك | نص قصير | ✅ |
| وصف التاسك | نص مفصل | ✅ |
| رابط مرجعي | URL | ❌ |
| Deadline | تاريخ | ✅ |

---

## حالات التاسك:
| الحالة | الوصف | من يغيرها |
|--------|--------|----------|
| `Pending` | وصل للـ Leader ولسه ما اتوزعش | - |
| `Assigned` | اتوزع على Agent | Leader |
| `In Progress` | الـ Agent بدأ فيه | Agent |
| `Done` | الـ Agent خلصه | Agent |
| `Revision` | محتاج تعديل | Leader / Account Manager |

# 🔍 4. Drill-Down System

## الوصف
نظام يتيح للمديرين الضغط على أي رقم إحصائي لمعرفة العملاء أو الموظفين اللي بيشكلوا الرقم ده.

---

## كيف يشتغل؟
1. في أي KPI Card (مثل: "اجتماعات محجوزة: 25")
2. الـ Manager يضغط على الرقم
3. يظهر Pop-up / Drawer بجدول يحتوي على:
   - أسماء العملاء أو الموظفين اللي بيشكلوا الرقم ده
   - تفاصيل مختصرة لكل واحد
   - زرار "عرض التفاصيل" للتعمق أكتر

## متاح في:
- Chief Sales Dashboard
- TeleSales Manager Dashboard (موجود بالفعل)
- Sales Manager Dashboard (موجود بالفعل)
- Head Account Manager Dashboard
- Head Technical Dashboard
- كل الـ Team Leaders
